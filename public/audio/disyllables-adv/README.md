# 高阶双音节词录音 (HSK 7-9) — Test 2 用

会议决议 (2026-07-08): Test 2 听辨要用学生**不认识**的高阶词，
否则学过的词是"记得"而不是"听出来"的。

## 现在的内容 (2026-09-21)

Qi 的 `New_HSK_7-9_800_Disyllabic_Tone_Combinations.xlsx`：16 个声调组合 × 50 词 = 800 词，
yiyi 自动合成男声 + 女声两个版本。

- 800 词 → 795 个音频：5 对同音词共用一个录音
  (发觉/发掘、纯朴/淳朴、不屑/不懈、不乏/步伐、报复/抱负)。
- `words.tsv` — 每个录音对应的汉字、拼音、HSK 编号、有哪些声音版本。
- `quarantine.tsv` — **暂不进 Test 2 的词**，每行写了原因（见下）。音频文件仍在本目录。

## 目录与命名

    disyllables-adv/<声调组合>/<拼音1><声调1><拼音2><声调2>.<声音>.mp3
    例: 21/hu2po1.female.mp3、21/hu2po1.male.mp3

- ü 写作 v (`ban4lv3` 伴侣)，隔音符号去掉 (`bei1ai1` 悲哀)。
- 文件夹名 = 声调答案；文件名里的声调必须与文件夹一致，否则构建时跳过。
- 同一个词有几个声音文件，播放时就随机选一个（和单音节多声音同一规则）。
- 旧的单声音 `.m4a`（没有 `.<声音>` 后缀）也支持，将来 Qi 真人录音可以直接放进来。

## Test 2 如何使用

只有 Test 2 读这个目录 (`DISYLLABLE_ADV_BY_PAIR`)。Practice I/II/V 等练习仍然只用
`disyllables/` 里的常用词 (`DISYLLABLE_BY_PAIR`)，不受影响。3+3 组合 Test 2 本来就不出。

## 放新录音 / 恢复隔离的词之后

    node scripts/buildDisyllableManifest.mjs

## 质量检查 (2026-09-21 这一批)

合成语音可能把多音字读错调，所以这批音频入库前做了三层检查：

1. **文件名 ↔ 词表**：800 行拼音逐一对上音频文件，795 个音频全部有主，无歧义。
2. **语言学筛查**：8 个独立审查 agent 标出可能读错的多音字、口语轻声、标注疑点（90 个词）。
3. **声学检查**：对每个音频提取基频曲线，按声调组合建模；男女两个声音都偏向另一个声调才算证据。
   针对语言学预测的具体误读逐个检验——绝大多数（重重、标识、发型、非得、湖泊…）音频明确支持标注的声调，
   即合成读对了。

检查不出来的问题只能靠耳朵：`quarantine.tsv` 里的词请 Qi 听一遍，没问题就删掉那一行并重新构建。

`node scripts/audit-recordings.mjs --adv` 再用 Deepgram 核对"说的是不是这个词"（不查声调）。
